# 🌍 Language Translator

A modern and responsive Language Translation Tool built using HTML, CSS, and JavaScript.  
This web application allows users to translate text between multiple languages instantly using a Translation API. The project also includes Text-to-Speech and Copy Text functionality with a premium animated user interface.

---

## ✨ Features

- 🌐 Translate text into multiple languages
- 🔊 Text-to-Speech support
- 📋 Copy translated text instantly
- 🎨 Modern glassmorphism UI
- 🌍 Floating language decorations & flags
- ⚡ Fast API-based translation
- 📱 Fully responsive design
- ✈️ Creative animated interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Translation API
- Web Speech API

## 🚀 How to Run the Project

1. Download or clone the repository
2. Open the project folder in VS Code
3. Install Live Server extension
4. Right click on `index.html`
5. Click on `Open with Live Server`
6. Start translating instantly

---

## 💡 How It Works

1. User enters text
2. Selects source language
3. Selects target language
4. Translation API processes the request
5. Translated text appears on screen
6. User can copy or listen to translated text
